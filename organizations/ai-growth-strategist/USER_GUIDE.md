# AI增长战略官｜帝王使用指南

帝王只需说明想要的业务结果，例如：

- “分析我们下一季度最值得验证的增长机会。”
- “拆一下三家竞品和一个替代方案，告诉我能学什么、不能抄什么。”
- “设计短视频、小红书和私域的客户培育与复购路径。”

执政官会自动选择 Skill、读取材料、检索知识、请相关组织复核、生成候选并运行门禁。帝王无需指定文件、字段、测试或技术实现。

当前为设计完成、等待真实任务试运行的阶段。交付会明确哪些是事实、推断、假设和未知，也不会自动投放、发布、联系客户或改变价格与成交规则。

如帝王只说“给我一套完整获客增长方案”，系统会自动按“机会分析 → 竞争对标 → 内容与客户增长”完成基础串联，不需要逐个技能确认。当前先交付可用的业务层、安全层和验收层；更复杂的证明、回放与大样本能力后续逐步增强。

当前基础版已经能够保存一次运行。帝王后续要求修改时，系统会保留旧版本、生成新版本，并自动重做受影响的下游部分；任务中断后沿用原项目继续。需要 AI品牌官、AI成交官或 AI组织官协作时，交接包只引用已固定版本，不会偷偷切换为后来修改的内容。帝王正式验收后，当前版本封闭，后续变化另建新版本。

整条三技能成果经帝王验收后，控制中心能够把机会简报、对标机制图和内容客户增长计划发布到当前项目的正式共享区，并逐项绑定项目级版本与文件指纹。中途停止时会沿用已经固定的发布计划恢复；三项全部成功后才生成完成回执。这里是项目内部交接，不会把内容发到公网、投放广告或联系客户；未验收、未重做完整或文件被改动的候选不会进入正式共享区。

如果在保存成果时突然断电或程序中断，帝王只需重复原来的一句目标。系统会核对事务记录和成果哈希，从原运行继续，不会重建一套重复任务。

可直接说：“AI增长战略官，给我一套完整获客增长方案。”控制中心会按增长机会、竞争对标、内容客户的顺序选择三个技能。当前组织仍在设计验收阶段，正式任务仍回退到现有成熟能力链，不会冒充已上线。

基础版一键自检：在本组织目录运行 `run-basic-self-check.ps1`，只检查当前三层基础闭环并设置清晰停止边界。

后续增强阶段如需运行全部深度证明，再使用 `run-self-check.ps1`。深度自检已按核心功能、检查点生成器和组织自检分层执行，任一层异常都会在明确时限内停止并清理后台任务，不会再次持续运行数小时。
